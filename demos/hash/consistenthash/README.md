# 一致性哈希 (Consistent Hash) 演示程序

## 简介

这是一个完整的一致性哈希实现，演示了分布式系统中常用的一致性哈希算法。该实现支持动态添加和删除节点，并能保持良好的负载均衡。

## 核心特性

1. **虚拟节点**：每个物理节点映射到多个虚拟节点，提高负载均衡性
2. **动态添加节点**：支持在运行时添加新节点
3. **动态删除节点**：支持在运行时删除节点
4. **负载均衡**：通过虚拟节点机制实现较为均匀的数据分布
5. **最小化数据迁移**：添加/删除节点时，只有部分数据需要重新分配

## 实现原理

### 哈希环
- 使用 SHA256 算法计算哈希值
- 将哈希值映射到 0 到 2^32-1 的环上
- 通过二分查找快速定位数据应该存储在哪个节点

### 虚拟节点
- 每个物理节点创建多个虚拟节点（默认150个）
- 虚拟节点均匀分布在哈希环上
- 提高数据分布的均匀性，避免数据倾斜

### 数据定位
- 对数据key计算哈希值
- 在哈希环上顺时针查找第一个大于等于该哈希值的虚拟节点
- 返回虚拟节点对应的物理节点

## 运行演示

```bash
# 运行主程序
go run main.go

# 运行测试
go test -v
```

## 演示流程

程序会依次演示以下场景：

1. **初始化3个节点** (node1, node2, node3)
   - 显示1000个键的分布情况
   
2. **添加新节点** (node4)
   - 观察数据重新分布
   - 只有部分键发生迁移
   
3. **删除节点** (node2)
   - 观察被删除节点的数据重新分配
   
4. **批量添加节点** (node5, node6)
   - 观察5个节点的负载均衡情况
   
5. **批量删除节点** (node4, node5)
   - 最终保留3个节点

## 性能特点

- **查找效率**：O(log N)，N为虚拟节点总数
- **添加节点**：O(V log N)，V为虚拟节点数量
- **删除节点**：O(V log N)
- **空间复杂度**：O(N)

## 应用场景

1. **分布式缓存**：如 Memcached、Redis 集群
2. **负载均衡**：请求分配到不同服务器
3. **分布式存储**：数据分片存储
4. **CDN节点选择**：选择最近的CDN节点

## 主要数据结构

```go
type ConsistentHash struct {
    hashRing     map[uint32]string // 哈希值 -> 节点名称
    sortedHashes []uint32          // 排序后的哈希值列表
    virtualNodes int               // 每个物理节点的虚拟节点数量
}
```

## 主要方法

- `NewConsistentHash(virtualNodes int)`: 创建一致性哈希实例
- `AddNode(nodeName string)`: 添加物理节点
- `RemoveNode(nodeName string)`: 删除物理节点
- `GetNode(key string)`: 获取key对应的节点
- `PrintDistribution(keys []string)`: 打印键的分布情况

## 示例输出

```

Node node3: 327 keys (32.70%)

Node node1: 302 keys (30.20%)
```

从输出可以看到，通过虚拟节点机制，数据在各节点间分布相对均匀。
